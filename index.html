FAQ & Troubleshooting

How do I prevent API rate limits (HTTP 429)?

You can paste multiple free Gemini API keys separated by commas into the configuration settings tab. The script will automatically rotate keys when quota limits are reached.

What does the Panic Kill Switch do?

Pressing Shift + \ instantly terminates all active polling loops, removes injection elements, stops dashboard spoofing, and restores the original environment across all parent and child frames.

How do I show or hide the Material You controller?

Use the keyboard shortcut Shift + / to toggle the visibility of the primary controller container at any time.
